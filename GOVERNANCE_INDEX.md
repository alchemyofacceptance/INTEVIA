## How to read this index

This index improves discoverability. It does not confer authority, ratify an artefact, prove canon status, change a Human decision, or establish that an indexed claim remains current.

For each object, distinguish:

- path presence;
- document status stated by that object's own bytes;
- verification method and date;
- exact authority source, if any; and
- limitations on what the index can establish.
